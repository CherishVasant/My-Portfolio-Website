Technical Report

Cloud Security in Remote Patient Monitoring Systems

A comprehensive machine learning pipeline for network traffic analysis and multi-class cyberattack detection using the Edge-IIoTset benchmark dataset.

Machine Learning Cybersecurity IoT Security Remote Patient Monitoring Ensemble Learning Python

Problem & Motivation

Remote Patient Monitoring (RPM) systems transmit sensitive health telemetry from resource-constrained IoT devices to cloud servers. Due to their decentralized nature, these channels are highly vulnerable to network-based attacks which can compromise data integrity, steal patient information, or disable medical devices entirely. Building robust, real-time Intrusion Detection Systems (IDS) customized for IoT protocols is critical to ensuring patient safety and securing health networks. This project leverages the modern Edge-IIoTset dataset to develop a highly accurate, multi-class cyberattack detection pipeline capable of identifying 14 distinct attack types and normal traffic.

Approach & Pipeline Overview

The system is built as a reproducible, end-to-end machine learning pipeline that scales and processes network traffic features to yield class predictions. The workflow is organized into the following sequential steps:

  1. Data Integration & Cleaning: Combines multi-source network packet dumps, resolves missing values, replaces infinite network metrics, and cleans invalid fields.
  2. Feature Engineering & Standardization: Builds advanced protocol flags, handles temporal cycles (hour/minute sinusoids), and standardizes numerical values using a StandardScaler.
  3. Feature Space Reduction: Leverages variance thresholds, correlation analysis (removing collinear features), and Recursive Feature Elimination (RFE) with a Random Forest estimator to scale features down to the 30-40 most informative predictors.
  4. Model Benchmarking: Benchmarks 8 diverse classifiers—ranging from simple Decision Trees to advanced tree ensembles (XGBoost, CatBoost, Random Forest, Gradient Boosting), Bagging, Voting, and Stacking Classifiers.
  5. Ensemble Stacking: Combines prediction probabilities of top-performing estimators (XGBoost, CatBoost, Random Forest) via a meta-learner (Logistic Regression) to boost final accuracy.

Data & Preprocessing

The pipeline processes traffic data from the Edge-IIoTset dataset, specifically tailored for IoT security benchmarks. The raw dataset is heavily imbalanced across classes (ranging from roughly 1,001 to 24,301 samples per class); SMOTE oversampling is applied to the training split only to correct this imbalance, while the held-out test set is left untouched to preserve a realistic evaluation.

💡 Preprocessing Highlight: Real-world network metrics often contain missing (NaN) or infinite values (e.g. rate fields calculated during division by zero). These are resolved by zero-filling missing entries, replacing infinite values with large finite bounds, and clipping extreme outliers to secure numerical stability during gradient calculations.

The dataset includes the following 15 classes (14 cyberattack categories + normal traffic):

  • Malware & Entry: Backdoor, Vulnerability Scanner, OS Fingerprinting, Uploading Attacks, Ransomware.
  • Denial of Service (DoS): DDoS (HTTP, ICMP, TCP, UDP).
  • Eavesdropping & Authentication: Man-in-the-Middle (MITM), Port Scanning, Password Attacks.
  • Web Attacks: SQL Injection, Cross-Site Scripting (XSS).
  • Baseline: Normal Traffic.

Model & Training Architecture

Model training was executed in a structured benchmark framework using 8 machine learning estimators. Feature inputs are standardized using standard scaling to ensure balanced feature weight distribution during gradient boosting and distance metrics computations.

Key Hyperparameters and Setup:

  • Random Forest: 100 estimators (n_estimators=100); remaining parameters left at scikit-learn defaults (Gini impurity criterion).
  • XGBoost: Trained with library default hyperparameters; multi-class softprob objective inferred automatically for the 15-class target.
  • CatBoost: Trained with library default hyperparameters (silent training mode); no manual tuning applied.
  • Stacking Classifier: Meta-model: Logistic Regression; base estimators: Random Forest, XGBoost, and CatBoost.
⚠️ Cybersecurity Trap (Topology Leakage): Early test iterations yielded near-perfect performance. Investigation revealed that the models were memorizing network IP addresses (ip.src_host, ip.dst_host) instead of actual packet properties. Removing these identifier columns forced the models to learn real traffic patterns (packet sizes, rates, inter-arrival times), ensuring generalizability to unseen networks.

Key Learnings & Engineering Judgment

  • Network Topology Overfitting: Standard network captures include IP address and MAC ranges. Dropping these during preprocessing is critical to prevent models from learning the topology of the training network instead of general traffic anomalies.
  • Handling Protocol Anomalies: Feature distributions in cybersecurity datasets exhibit huge variance (e.g. packet rates jumping from 0 to millions in microseconds). Scaling these using StandardScaler or log transformations is required to stabilize model coefficients.
  • Model Latency vs Accuracy Trade-off: While the Stacking Classifier offers the highest accuracy (99.02%), its model size (exceeding 250MB) and inference latency make it unsuitable for real-time edge deployment. Single estimators like XGBoost (2.3MB) achieve a virtually identical accuracy (99.01%) with a fraction of the computational footprint.

Summary

Final Chosen Model: Stacking Classifier (base estimators: Random Forest, XGBoost, CatBoost; meta-learner: Logistic Regression).

Headline Result: Achieved 99.02% multi-class classification accuracy (99.02% precision, recall, and F1-score) on network-level intrusion detection, classifying normal traffic alongside 14 threat types with minor performance overhead.

Real-world Relevance: This lightweight tree ensemble can be deployed directly onto edge nodes or gateways in remote patient monitoring systems, monitoring incoming and outgoing network frames in real-time to detect security breaches before patient health telemetry is compromised.
